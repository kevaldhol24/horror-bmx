## Free sources worth using next
- Quaternius (quaternius.com) — CC0 characters with animations, cars, nature. Downloads are via Google Drive links on each pack page.
- Kenney (kenney.nl) — CC0 everything. Some Kenney packs are mirrored in Kenney's GitHub starter kits.
- Poly Haven / ambientCG — CC0 textures/HDRIs.
- Freesound (check each sound's license; prefer CC0).
- Mixamo — free animations for rigged humans (Adobe account; licence allows use in games).
