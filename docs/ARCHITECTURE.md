# Architecture

Godot 4.6.2, GDScript, Compatibility renderer. One scene; everything is created in code from `scripts/game.gd`.

```
Main (game.gd)
├── WorldEnvironment (sky shader, fog, glow, tonemap)
├── DirectionalLight3D "moon" (dim red, from the horizon ahead, no shadows)
├── World (world.gd)            chunks + props + obstacles + light pool + Watchers
├── Player (player.gd)
│   ├── Model (bike_model.gd)   procedural BMX + rider (IK)  — rotated 180°, model space is +Z forward
│   │   └── Front/LampAnchor/SpotLight3D  (headlight, the only shadow-casting light)
│   └── OmniLight3D             warm back-fill so the rider reads against the dark
├── ChaseCamera (chase_camera.gd)
├── CanvasLayer(1) → ColorRect  VHS post shader (reads screen texture)
├── CPUParticles3D              spores that follow the camera
├── AudioDirector
└── GameUI (CanvasLayer 5)      HUD / menus / input
```

## Road coordinates
`road_path.gd` defines the road as functions of distance `s` (metres):
- centre `(center_x(s), height(s), -s)` — sums of sines for curves/hills, so it's endless and deterministic.
- `right(s)`, `forward(s)`, `basis_at(s)`, `point(s, lat)`, `ground_height(s, lat)` (road → shoulder → ditch → hills).

Everything uses `(s, lat)`: the player, obstacles, props, camera ground clamp. The lateral offset is applied
along the horizontal right vector, which is accurate for the gentle curvature used (|dx/ds| < ~0.25).

## World streaming (`world.gd`)
- Chunks are 24 m. Keep 1 behind / 9 ahead (~216 m, fog hides the edge).
- Each chunk: road mesh (5 columns, rows every 2 m, UV = (lat, s) for the road shader) + terrain mesh
  (±90 m, vertex colour R = gravel shoulder) + props + obstacles. RNG seeded by chunk index → same world every run.
- Zone = `floor(s / 420) % 3` → TOWN, WOODS, CEMETERY. `_decorate_*` place KayKit props via `_prop()`, which
  orients models in a flattened road frame and turns their +Z front toward the road.
- **Obstacles** live in global 4 m slots (`_slot_has_obstacle(k)`), with no two consecutive slots filled.
  Each is a dict `{type, s, lat, half_w, half_len, height, node, hit}` appended to `World.obstacles`.
- **Lights:** street lights/lanterns register lamp positions in `lamps`; a pool of 5 OmniLights is reassigned
  every 0.2 s to the lamps nearest the player (mobile can't afford one light per lamp). Flicker = noise + random drop-outs;
  `flicker_burst()` makes them all stutter (Watcher, lightning).
- **Watcher:** spawned ~7.5% of chunks after 260 m. When the player is 18 m away: `watcher_seen` signal →
  sting/buzz/glitch in `game.gd`, lights burst, figure hides after 0.45 s.

## Player (`player.gd`)
State in road coords: `s, lat, speed, air, vy`. `_physics_process` integrates speed toward `cruise_target()`
(7.5 m/s + s/260, max 15.5), lateral velocity from smoothed steer, gravity for hops/launches, then `_place()` builds the
transform: road basis × yaw (from lateral velocity) × lean × pitch. Crash switches to a ballistic tumble.
Signals: `crashed(reason)`, `hopped`, `landed(impact)`.

## Collisions (`game.gd: _check_collisions`)
Axis-aligned in (s, lat) against each obstacle's half extents (+ bike half width 0.28).
- `ramp` → `player.launch()`; `rough` → `rough_t` (shake, slower, rattle sound).
- Everything else crashes unless `player.air >= obstacle.height` (so hopping clears low stuff; barricades are 1.2 m — must steer).

## Bike + rider (`bike_model.gd`)
All geometry from primitives (CylinderMesh/TorusMesh/BoxMesh/CapsuleMesh/SphereMesh). Each frame:
wheels/crank rotate, front assembly rotates around the head-tube axis, pedal positions are computed, then the rider is
re-posed: pelvis between seated/standing (`effort`), torso lean, analytic 2-bone IK for legs (to the pedals) and arms
(to the steered grips). Limbs are capsules stretched between joints.

## Rendering budget (mobile)
- Compatibility renderer, MSAA 2×. 1 directional (no shadow), 1 shadowed spot (headlight), ≤5 omni (pool) + rider fill
  + Watcher glow.
- Fog density ~0.0105, sky radiance 32, reflections off.
- VHS post is one full-screen pass with 3 texture reads. Drop `aberration`/`grain` if a device struggles.
- Props are plain KayKit glTF instances (one shared texture per pack).

## Audio (`audio_director.gd`)
Loops: synth theme, ambience, tyre roll (pitch/volume by speed), freewheel ticks (coasting/air), rough-road rattle.
One-shots: thunder, crash, hop, land, sting, buzz, heartbeat (unused yet). All WAVs are generated by `tools/gen_audio.py`.
